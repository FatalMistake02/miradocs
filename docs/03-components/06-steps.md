## Example

:::steps
### Install dependencies
Run the package manager's install command.
### Start the preview
Run the development command and open the local URL.
### Build the site
Generate the static output for deployment.
:::

## Usage

Wrap level-three headings and their content in `steps`. The headings are numbered in order.

```md
:::steps
### Install dependencies
Run the install command.
### Build the site
Generate the static output.
:::
```

The headings also appear as nested entries in the page outline. Use a separate steps block to restart numbering.

## Customize

The wrapper uses `.steps`. Numbers are generated by a CSS counter on `.steps h3`.

```css
.steps { padding-inline-start: 44px; }
.steps h3::before {
  background: var(--surface);
  border-color: var(--border);
  color: var(--text);
}
```

Use logical properties such as `padding-inline-start` so custom styles also work in right-to-left layouts.
