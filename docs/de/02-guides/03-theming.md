---
title: Themes und Stile
description: 'Passe Schriften, Farben und Komponenten in theme/ an.'
---
Trage Stylesheets in `styles` ein; sie werden in dieser Reihenfolge nach dem Standard-CSS geladen. Gemeinsame Variablen bestimmen das Layout, separate Farbwerte die Themes. `--font` steuert Text, `--mono` den Code. Die Navigation verwendet `--sidebar-font-size`, `--sidebar-group-font-size` und `--outline-font-size`. Mit `{.meine-klasse}` an einer Direktive gestaltest du eine einzelne Instanz. `group` kapselt gewöhnliches Markdown für eigene Stile.

## Eigene Stile hinzufügen

```json title=miradocs.config.json
{
  "theme": "theme",
  "styles": ["tokens.css", "components.css"]
}
```


## Farben und Layout

```css title=theme/tokens.css
:root {
  --radius: 10px;
  --sidebar-width: 248px;
  --content-width: 820px;
  --accent: #9c2472;
}
```

```css title=theme/tokens.css
:root {
  --bg: #ffffff;
  --text: #202020;
}
html[data-theme="dark"] {
  --bg: #141414;
  --text: #e8e8e8;
}
@media (prefers-color-scheme: dark) {
  html:not([data-theme="light"]):not([data-theme="dark"]) {
    --bg: #141414;
    --text: #e8e8e8;
  }
}
```

```css title=theme/tokens.css
:root {
  --accent-gradient: linear-gradient(110deg, #ff0951b8, #f50983);
  --header-divider: var(--accent-gradient);
}
```


## Typografie

```css title=theme/tokens.css
:root {
  --font: "Segoe UI", system-ui, sans-serif;
  --mono: "Cascadia Code", ui-monospace, monospace;
}
```

```css title=theme/tokens.css
@font-face {
  font-family: "My Sans";
  src: url("../fonts/my-sans.woff2") format("woff2");
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
}
:root {
  --font: "My Sans", system-ui, sans-serif;
}
```

```css title=theme/tokens.css
:root {
  --brand-font-size: 24px;
  --brand-font-weight: 500;
}
```
